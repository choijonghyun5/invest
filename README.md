# Study & Invest
정적 호스팅(GitHub Pages 등)에 올리면 PWA로 동작합니다.

- data.js: 자산/mock 시세 (`fetchPrices`를 실제 API 프록시로 교체)
- storage.js: localStorage, 기본 시작 데이터(현금 ₩100,000만 보유)
- portfolio.js / transactions.js / study.js: 계산, 매매, 공부 급여
- charts.js: 선·도넛 차트, mock 시계열 (`series`)
- market.js: 종목 상세 (`info`를 API로 교체), news.js: 뉴스·지표
- bank.js / stats.js / plan.js / game.js, views.js, app.js

## 실시간 시세 (worker v3)
1. `worker/worker.js`를 Cloudflare Workers에 붙여넣고 Deploy (무료, 키 불필요). **이전에 배포했다면 코드를 새 버전으로 교체해야 합니다.**
2. `js/api.js` 맨 위의 `API` 상수에 `*.workers.dev` 주소 입력 (앱 화면에는 주소 입력칸이 없습니다)

## ECOS 키 설정 (선택)
1. ecos.bok.or.kr/api 에서 인증키 신청
2. Cloudflare > Workers > invest-api > Settings > Variables and Secrets > Add > Secret, 이름 `ECOS_KEY`, 값에 인증키
3. Deploy. 앱에서 한국 기준금리와 국채 가격이 실제 금리를 따라 움직입니다.

## 채권 (js/bonds.js)
- 시장 탭 아래쪽 '채권 · 신규 발행'에서 한국 국채 3Y·10Y, 미국 국채 5Y·10Y를 살 수 있습니다. 매수하면 그 달에 발행된 시리즈를 사게 되고, 표면금리는 첫 매수 시점의 시장금리(0.125%p 단위)로 만기까지 고정됩니다.
- 가격은 남은 이자와 원금을 현재 시장금리로 할인해 계산합니다(금리가 오르면 가격 하락, 만기가 길수록 더 크게 움직임). 1좌 = 한국 ₩10,000 / 미국 $100.
- 이자는 한국 3개월, 미국 6개월마다 자동 입금되고 보유 기간만큼 일할 계산됩니다. 중도 매도하면 경과이자도 받습니다. 만기가 되면 마지막 이자와 원금이 자동 상환됩니다(알림·거래내역·실현손익에 반영).
- 기존에 갖고 있던 'KTB' 보유분은 '한국 국채 3Y · 기존'으로 유지됩니다.
- Worker `/ecos`는 국고채 10년(ECOS 817Y002 / 010210000)도 읽습니다. Worker를 최신으로 교체해야 합니다.

- 더보기 > 목표 자산: 목표 금액과 진행률, 달성 시 알림

- 월별 기록: 월마다 초기자산·공부 수입·투자 손익·배당·이자·기타·월말 자산·월 수익률 표시 (투자 손익 = 월말 − 월초 − 나머지 항목, 평가손익 포함)
- 포트폴리오: '기타' 항목 추가 (분류되지 않은 보유자산)
- 게임: 동전 던지기·주사위·룰렛·카드 뒤집기 애니메이션, 결과는 애니메이션이 끝난 뒤 토스트로 알림 (동작 줄이기 설정 시 짧게 표시)
- 게임머니 환전: 게임 화면에서 게임머니를 현금으로 환전 (1 G = ₩1 고정, 하루 한도 ₩5,000,000 고정). 환전액은 현금·거래내역(기타)·월별 기록 '기타'에 반영
- 시작 데이터는 현금 ₩100,000만 있는 빈 상태입니다. 테스트용 기능(600배속 타이머, 1개월 경과)은 제거했습니다. 기존 기기에 저장된 데이터는 더보기 > 시뮬레이션 초기화를 눌러야 새 시작 상태가 됩니다.
- 게임 확률: 배팅 금액이 1만 G를 넘으면 클수록 승리 확률이 낮아집니다 (10배마다 승산 ×0.1 감소, 최저 ×0.5). 각 게임 카드에 현재 승리 확률이 실시간으로 표시됩니다.
- 월별 기록 카드: 기본은 이번 달만 보이고, 아래 '지난 달 보기' 버튼으로 이전 달 카드를 펼치거나 접을 수 있습니다.

## 난이도 (js/data.js의 DIFF)
생활비·대출 금리도 DIFF에 있습니다. 보통 월 약 95만 원 / 어려움 월 약 107만 원이 청구되고(쉬움은 없음), 대출 금리는 쉬움 5.5% · 보통 7.5% · 어려움 9.5%입니다.
새 시뮬레이션 시작 화면에서 쉬움/보통/어려움을 고릅니다. 난이도마다 시작 금액·시간당 급여·공부 보너스 구간·게임 승리 확률 보정이 정해지고, 거래 수수료는 0.015%로 고정입니다. 더보기의 급여·수수료·보너스 설정 카드는 없앴고 현재 난이도 카드만 표시됩니다.

| | 시작 금액 | 시간당 급여 | 보너스(2/4/6/8시간 이상) | 게임 확률 |
|---|---|---|---|---|
| 쉬움 | 3,000,000 | 15,000 | 10/20/35/50% | ×1.00 |
| 보통 | 2,000,000 | 10,320 | 5/10/20/30% | ×0.85 |
| 어려움 | 1,000,000 | 7,000 | 3시간 2% · 5시간 5% · 8시간 10% · 10시간 15% | ×0.70 |
- 게임머니 시작 금액은 0 G입니다 (새 시뮬레이션·초기화 모두).
- 게임머니 충전: 1 G = ₩1로 **보유 현금에서 차감**됩니다. 현금이 모자라면 충전되지 않고(버튼 비활성·안내 문구), 게임머니가 남아 있어도 언제든 추가로 충전할 수 있습니다. 충전액은 거래내역(기타)·월별 기록 '기타'에 반영됩니다.
- 게임 결과 토스트(승리/패배 +N G)는 한 줄로 표시되도록 글씨 크기를 줄였고, 숫자와 G 사이는 줄바꿈되지 않습니다.

## 구글 드라이브 자동 백업 (js/backup.js)
- 더보기 > '구글 드라이브 백업'에서 연결하면 진행 상황(S 전체)이 내 드라이브의 **앱 전용 숨김 폴더**(`drive.appdata` 권한)에 `study-invest-backup.json`으로 저장됩니다. 드라이브의 다른 파일에는 접근하지 않습니다.
- 데이터가 바뀌면 최대 5분마다, 앱을 닫거나 백그라운드로 보낼 때(30초 이상 지났으면) 자동 백업합니다. '지금 백업', '백업에서 복원', '연결 해제' 버튼이 있습니다.
- 브라우저 전용 앱이라 액세스 토큰이 약 1시간 뒤 만료됩니다. 만료되면 화면을 한 번 터치할 때 자동 재연결을 시도하고(팝업이 잠깐 뜰 수 있음), 실패하면 '다시 연결' 버튼을 누르세요.
- 연결 정보는 `localStorage['si-gd']`에 따로 저장되어 백업 파일에는 들어가지 않습니다.

## 생활비 청구서 · 대출 (js/living.js)
**생활비 (보통·어려움)**
- 서울 자취 가정으로 30일마다 청구서가 발행됩니다: 월세·관리비·전기·가스(난방)·수도·인터넷·통신·식비·교통. 전기는 여름·겨울, 가스는 겨울에 더 나옵니다. 항목·금액은 `js/data.js`의 `BILLS_N`(보통)·`BILLS_H`(어려움)에서 바꿉니다.
- 청구서는 자동으로 빠지지 않고, **더보기 > 생활비 · 청구서**에서 `납부하기`(또는 `전체 납부`)를 눌러야 현금에서 차감됩니다. 미납이 있으면 홈에 알림 카드가, 더보기 탭에 빨간 점이 표시됩니다.
- 납부 기한은 발행 후 7일이고, 넘기면 청구액의 3%(`LATE`)가 연체료로 한 번 붙습니다. 오래 접속하지 않아 한꺼번에 발행된 청구서는 확인한 날부터 최소 2일의 여유를 줍니다.
- 납부는 거래내역 '생활비'에 기록되고, 월별 기록에는 '생활비' 줄로 따로 표시됩니다(투자 손익에 섞이지 않음).

**대출 (모든 난이도)**
- 더보기 > 대출 > `대출 받기`: 금액·기간(1~60개월)·상환 방식(원리금균등 / 만기일시)을 고르면 금액이 바로 현금으로 들어옵니다. 금리는 난이도별 고정, 최소 10만 원.
- 한도: 총 대출 잔액이 순자산을 넘을 수 없고 최대 3,000만 원입니다.
- 총자산은 **순자산(자산 − 대출 잔액)** 으로 계산합니다. 대출을 받거나 원금을 갚아도 총자산은 변하지 않고, 이자·연체료만 총자산을 줄입니다. 포트폴리오 비중은 대출 차감 전 자산 기준이며 '대출 (차감)'이 따로 표시됩니다.
- 원리금은 30일마다 청구서로 발행되고 직접 납부합니다(생활비와 같은 방식, 연체료 동일).
- 중도 상환: 전액 또는 일부, 수수료 없음, 경과이자만 정산합니다. 일부 상환하면 남은 회차의 상환 일정이 다시 계산되고 청구 주기가 오늘부터 다시 시작됩니다. 미납 청구서가 있으면 먼저 납부해야 합니다.
- 거래내역에 '대출' 필터(실행·원금 상환·이자)가 추가되었습니다.

**기존 저장 데이터**: 시작 금액은 새 시뮬레이션을 시작해야 바뀝니다. 진행 중인 보통·어려움 데이터는 업데이트 후 30일째부터 생활비가 청구됩니다.
